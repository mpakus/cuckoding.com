04 / Development status

Real progress.
No holographic promises.

Cuckoding is in active development. The source and local build instructions are available. This is not a signed or notarized public release.

Implemented in source

The foundation is here.

  • Local macOS menubar shell and browser workspace.
  • Named Codex and Cursor connections, model selection, and saved role assignments.
  • Arenas, Tabulas, draft tasks, and Codex-assisted brief/document planning.
  • Specification receipts and consented isolated worktree preparation and inspection.

Detection does not authorize an agent. A model catalog does not prove model access. Real-account acceptance remains open.

Still on the roadmap

The autonomous battle.

  • Bounded task execution by Implementors.
  • Independent Secutor review and automatic task movement.
  • Summa Rudis coordination and parallel role instances.
  • Live battle dashboards and verified public distribution.

Cursor task inference is not enabled. Start battle is not available yet. Follow the checklist for the actual boundary.
