03 / LEGAL ASKED US TO CLARIFY

The small print.
The big questions.

The dystopia is satire.
The engineering is serious.

Wait. Is this a real product?+

Yes. Cuckoding is the home of BOSS, a local coding-agent orchestrator currently in development. The robot spa is a joke. Markdown specs, isolated Git worktrees, checks and independent review are the actual work.

Am I actually surrendering control?+

No. You explicitly start work and choose the check command and reviewer. Ordinary workflows wait for integration. Autopilot requires separate authorization for a saved backlog. Pause and Stop remain available.

Does “local” mean the AI runs offline?+

The coordinator and dashboard run locally. Coding agents use your installed CLI tools and provider accounts, which may send data to their services and incur charges. The robot's holiday is not necessarily free.

Where can I get it?+

Follow the GitHub project for source and development updates. BOSS is at the macOS release-candidate stage. A signed public download and Linux runner acceptance are still pending; there is no finished installer to promise here.
