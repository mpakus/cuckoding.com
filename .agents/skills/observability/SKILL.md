# Observability

- Persist normalized events before broadcast with a durable sequence.
- Every sample and event carries the full correlation chain.
- Measured, reported, and estimated values stay distinct with `≈` for estimates.
- Store active and wall durations; record sleep gaps as events.
- Include coordinator, review and parallel worker sessions in battle accounting. Add plugin/knowledge dimensions only when those scoped features exist.
- Batch high-frequency updates; provide table alternatives for every chart and graph.
