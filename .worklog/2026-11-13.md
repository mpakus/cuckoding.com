- Adopted pattern: `opencode run --pure --format json` with
  `OPENCODE_PERMISSION={"*":"deny","read":"allow","glob":"allow","grep":"allow","list":"allow","external_directory":"allow"}`
  on read-only stages (`:plan`, `:resolve`, `:intake`, `:review`,
  `:merge_review`) and `--auto` only on isolated worktree `:implement`, plus
  requiring terminal `step_finish` (`reason: "stop"`) in the NDJSON stream.
- Rejected tradeoff: Kander passes prompts via positional `argv`, which risks
  macOS `ARG_MAX` limits on large review diffs / documentation intakes and
  leading-dash option parsing. Verified on installed OpenCode `1.18.30` that
  `opencode run --pure --format json` reads piped `stdin` directly, and built a
  streaming NDJSON state machine (`Boss.Agents.OpenCode`) so multi-megabyte
  tool-call streams never truncate the terminal `text` / `step_finish` events
  or retain `sessionID`.

## Beta gap audit, non-Codex retry hardening, and documentation synchronization

### Internal issues found and fixed
1. **Non-Codex explicit recovery & review retries (`ExecutionRetry`, `Retry`, `Deliveries`)**:
   - `ExecutionRetry.parent/1` and `ExecutionRetry.checked_parent/1` previously
     required `ModelCatalog.validate(parent.model_catalog) == :ok` unconditionally,
     which rejected timeout, checkpoint, and provider rate-limit (`start_checkpoint`)
     recovery on `Cursor Agent`, `Claude Code`, and `OpenCode` deliveries whose
     `model_catalog` is `{}` because Codex was not used.
   - `Deliveries.admit_retry/5`, `Deliveries.admit_timeout_retry/4`, and
     `Deliveries.admit_checkpoint_retry/4` previously re-read live `Roles.implementer()`
     and `Roles.analytic/1` instead of preserving `parent.implementer` and
     `parent.analytic`.
   - Fixed `Deliveries` to copy `parent.implementer` and `parent.analytic` on
     all explicit retries, updated `Retry.source/1` and `ExecutionRetry.source/1`
     to verify pinned role preservation, and scoped `validate_catalog/1` in
     `ExecutionRetry` so `{}` is accepted when all three pinned roles are non-Codex.
2. **Claude review `StructuredOutput` balance & lingering MCP helper tolerance**:
   - `Claude.complete?/1` now requires `MapSet.size(state.tools) == 0` so an
     unclosed `StructuredOutput` `tool_use` without a matching `tool_result`
     cannot pass review, and `Worker.claude_process/4` now shares
     `clean_envelope_exit?/1` so a lingering MCP helper reaped cleanly by
     `boss_guardian` (`cleanup: :group_empty`, `exit 0`, both EOFs) normalizes
     to `"outcome" => "exited"`.
3. **Release notice provenance test (`rel/test_package.exs`)**:
   - Added verification that `LICENSE`, `assets/node_modules/tailwindcss/LICENSE`,
     and `assets/node_modules/three/LICENSE` exist and are non-empty so
     `MIX_ENV=prod mix release.build` notice bundling cannot drift.
4. **Documentation & rules alignment (`README.md`, `AGENTS.md`, `CHANGELOG.md`, `docs/*.md`)**:
   - Synchronized `README.md`, `AGENTS.md`, `CHANGELOG.md`, `docs/AUTOPILOT.md`,
