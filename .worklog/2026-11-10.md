downstream stages of non-Codex execution:

   alongside `"Logged in (unable to fetch user details)"` for an expired session
   while headless `agent --print` exited 1 (`Authentication required`). Detector
   now classifies this as `:stale` ("expired or unverified session — re-run login").
2. `Cursor.implement_args/0` omitted `--force`, which Cursor's headless CLI
   requires to apply file edits in `--print` mode; added `--force`.

   on Codex `--output-schema` without spelling out exact JSON keys in the prompt
   text, causing non-Codex planners to fail validation; added explicit key/type
   contracts and prose-stripping JSON extraction in `Cursor.report/1`.

   runners ignored (`validation_code: nil`); `run_envelope_stage` now returns
   `report_bytes` and `validation_code` and caps stdout buffering at 512 KiB.

   Cursor even if `analytic` or `reviewer` was Codex, causing `:catalog_invalid`
   mid-run; now discovers the Codex catalog whenever any pinned role is Codex.
