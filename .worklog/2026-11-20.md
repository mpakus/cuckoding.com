  1. **Obsidian & Cyan-Emerald Design System (`assets/css/app.css`, `assets/js/autopilot_flow.mjs`)**: deep obsidian canvas (`--color-paper: #090b10` with subtle top radial cyan/sky ambient glow), elevated carbon-slate panels (`--color-surface: #10141d`, `--color-surface-raised: #161c28`), crisp 1px hairlines (`--color-line: #1f2736`, `--color-control-line: #313d54`), electric cyan-emerald accents (`--color-forest: #2dd4bf`), high-contrast slate ink (`#f1f5f9` / `#cbd5e1` / `#7c8aa5`), concentric rounded corners, `overscroll-behavior: contain` on overlays, and synchronized Three.js dark WebGL palette.
  2. **Global Command Shell (`root.html.heex`)**: 52 px sticky blurred glass command bar (`BOSS · LOCAL ORCHESTRATOR`, `Projects`, `Agents`) with global footer removed.
  3. **Project Workspace (`/projects/:id`)**: single-row command bar (`Roles & models`, `Capacity` popover disclosure, `Prompt task control`, `Sync specs`, `Autopilot`), compact horizontal `Autopilot` HUD strip (collapsing task manifest, CLI check override, safety/billing rules, settled intake attempts, and previous batches into `<details>` pills so all 5 Kanban columns remain above the fold), and minimalist Kanban cards (`position: relative` anchoring `.sr-only` revision/path provenance for zero horizontal overflow at `320px`).
  4. **Slide-Over Task Drawer (`#task-drawer`)**: sticky status/path header, Managed Workflow action bar (auto-collapsing settled queue/delivery history while keeping active/`ready_to_merge` workflows open), Activity & Notes, Specification, and collapsed `Advanced & manual diagnostics` `<details>` housing manual Codex runs, candidate checks/reviews, and transition events.
  5. **Projects Launchpad (`/`) & Agents Matrix (`/agents`)**: progress-bar repository cards + compact `Connect repository` panel with collapsed optional settings on `/`; 3-column Orchestration Roles deck above a 4-column Connected CLI Agents row with collapsed `Catalog` model toggles on `/agents`.
