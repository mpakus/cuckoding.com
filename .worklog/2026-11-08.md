# 2026-11-08 — Remember this browser

Scope: opt-in local browser access across a BOSS restart with the existing
loopback, Origin, CSRF, signed session and LiveView gates. Baseline: clean main
at ff9de0b. Toolchain: Elixir 1.20.3 on OTP 28.

Research: `xerj search --prefix bossrefs 'persistent browser session authentication cookie' -k 3 --full 1200`
could not reach the index. Direct `rg` for remember-me and cookie terms found no
matching reference implementation. RFC 6265 §8.5 documents that cookies are
shared across ports. Followed the locked Plug cookie API and the existing BOSS
unlock pipeline. Chose a path-scoped cookie and a private hashed verifier over
persisting the endpoint signing key or sending credentials in a URL.

The unlock form can remember one browser per private data directory for 30
days. The LocalAccess server serializes enrollment and writes only an absolute
expiry and SHA-256 digest to a mode-0600 file with atomic replacement. The
HttpOnly, SameSite=Strict cookie is scoped to the unlock path and named by port.
Automatic unlock issues the existing signed session. Explicit console revocation
removes future automatic access. The localhost cookie boundary is documented in
README.md.
