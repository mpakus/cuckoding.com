## Findings and decisions
1. **Lingering MCP/plugin descendants on Cursor Agent (`:lingering_processes`)**:
   After `--model auto` took effect, Cursor Agent completed planning in 43–75s
   with `exit_code: 0` and emitted a valid `"type":"result"` JSON envelope, but
   user-configured MCP stdio helpers in its process group lingered past 500ms
   before `boss_guardian` terminated and reaped them (`cleanup: :group_empty`,
   `eof: %{stdout: true, stderr: true}`, `outcome: :failed, reason: :lingering_processes`).
   - `Boss.Deliveries.Worker` (`run_envelope_stage/8` and `cursor_review_once/5`)
     now accepts `:lingering_processes` when `cleanup == :group_empty`,
     `exit_kind == :exit`, `exit_code == 0`, both stream EOFs are true, and a
     valid terminal result envelope decodes cleanly, normalizing receipt
     `"outcome" => "exited"`. `Boss.Agents.Process` and raw Codex/check stages
     retain their existing `:lingering_processes` failure contract.
   - `Cursor.notice/2` and `Claude.notice/2` never echo a `"type":"result"`
     success envelope's assistant text into `receipt["reason"]`.
2. **Multi-turn prose containing `{` before final JSON in Cursor `result`**:
   Cursor's `--output-format json` concatenates pre-tool assistant text turns
   with the final JSON object. Replaced first-brace slicing in `Boss.Agents.Cursor`
   with a string-aware balanced-brace scanner that returns the last valid
   top-level JSON object.
3. **Autopilot `cancel/4` vs `Manager` `advance/1` race (`{:error, :request_finished}`)**:
   Signaling `Runs.stop` before `change(..., :cancel, ...)` allowed a fast worker
   exit to trigger `Autopilot.advance` and mark the still-`running` batch
   `blocked` before `cancel` entered its SQLite transaction, while reversing the
   order would violate immediate Stop when SQLite is locked. Added an ETS
   `:boss_autopilot_cancelling` guard (`{:heir, Process.whereis(:init), :none}`)
   around `Autopilot.cancel/4` so `advance_batch/3` yields `:waiting` while
   cancellation commits, keeping immediate Stop under SQLite lock.
