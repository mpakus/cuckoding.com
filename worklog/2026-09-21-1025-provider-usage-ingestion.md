Acceptance: ingest only bounded redacted terminal usage; keep provider-reported tokens distinct from unavailable or estimated cost; do not let malformed telemetry silently create a false number or leak raw output; preserve idempotency on replay and report exact verification commands and results below.

Implementation: `OutputParser.usage_events/2` reuses the redacted JSONL scanner and adapter event decoder, selecting only terminal usage and Claude's separate reported cost field. `ActivityStream.record_provider_messages/3`, already called by both delivery and board planning before exit-status handling, now calls each adapter's `collect_usage/2` and `Accounting.record_usage/4`. Valid replays retain one usage row. Empty or malformed usage stores no false amount and appends a safe warning; absent usage remains absent. No billing mode is inferred, so Codex/Cursor cost stays unavailable unless an explicitly reported cost exists.
