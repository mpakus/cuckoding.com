## 2026-09-20 — Orchestration failure and agent-error hardening

Acceptance criteria restated before implementation:

- Planning and delivery worker errors, including unexpected exceptions, must
  never leave a run silently stuck in `running`.

- Every blocked or failed run must show an obvious reconnect-safe alert with a
  recovery destination, while preserving the existing last-5,000-line live log
