## Implementation

- New Start snapshots freeze `task_selection: skip-task-v1`. Skip uses the same
  guarded control revision, exact current task and immediate transaction. Permit
  clean pauses and validated task-local provider blocks/transient failures/review
  exhaustion; reject active workers, final stages, native/policy failures, historical
  grants, expired budgets, changed bindings and unknown cleanup.
- Confirm affected titles before marking the current task skipped and its
  transitive dependents deferred. Preserve task drafts, frozen snapshots, old
  attempts, failed edits/worktrees, reviewed head, counters and deadline. Shared
  dependents appear once. Only failed attempts explicitly consumed by Skip count
  as settled for subsequent Pause/Resume/restart.
- Independent tasks use fresh preparation from the reviewed head. Paused battles
  remain paused; an all-omitted battle with no completed tasks stops without more
  inference. Final criteria digests and prompts bind the retained subset plus
  omissions; configured checks and independent review still gate the result.
  Terminal `partial` releases the Arena lock without emitting `battle.completed`.
- Arena confirmation, omission counts and unfinished card statuses reuse existing
  LiveView/session guards and disclosures. Agents/Team and native grants are unchanged.
